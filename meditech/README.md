# Meditech

Progetto per l'analisi e la visualizzazione di indicatori territoriali e dati geospaziali.

## Struttura

- `app.py`: applicazione principale
- `static/`: asset e pagina web
- `analysis_output/`: risultati generati dall'analisi

## Avvio

- Installa le dipendenze con `pip install -r requirements.txt`
- Avvia l'app con `python app.py`
