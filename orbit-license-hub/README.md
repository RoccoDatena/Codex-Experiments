# Orbit License Hub

Piattaforma multi-tenant per la gestione di tenant, applicazioni, licenze e utenti.

## Struttura

- `backend/`: API Spring Boot e logica server
- `frontend/`: interfaccia Angular amministrativa

## Avvio

- Backend: `backend\mvnw.cmd spring-boot:run`
- Frontend: `npm run start` dentro `frontend/`
